# 开发路线与进度

> 更新时间：2026-09-25 · 交付截止：2026-09-28

## 时间约束下的取舍

整个项目只有 3 天工期，所以从一开始就定了一条原则：
**每个阶段结束时都必须是可运行、可演示的状态**，绝不出现「做到一半跑不起来」。

因此顺序是「先打通闭环，再加深亮点」，并且对次要功能做了明确降级：

| 决定                 | 原因                                                                                                          |
| -------------------- | ------------------------------------------------------------------------------------------------------------- |
| epub 解析降到最后    | 解析库选型与目录结构处理容易翻车，而 txt/md 已能验证「导入资料 → 生成路径」这条链路                           |
| 不引图表库           | 掌握状态用 CSS 画热力格即可，引一个图表库要多几百 KB 换一个视觉效果，不划算                                   |
| 单测只覆盖纯逻辑     | 排期算法与记忆检索的 bug 最隐蔽、最难靠手测发现；UI 的问题手测成本更低                                        |
| 不引 Markdown 解析库 | 模型回复里高频出现的只有代码块、行内代码、加粗、列表，自己写 120 行足够，还能避免流式输出时半截语法的渲染闪烁 |

## 阶段与状态

### P0 · 项目骨架 ✅

- Vite 8 + React 19 + TypeScript 6 + Tailwind 4 工具链
- ESLint 10 / Prettier / Vitest 配置
- 完整数据模型（`src/types/models.ts`）
- 应用外壳：桌面侧边栏 + 移动端底部导航
- 六个功能域的占位路由

### P1 · 主循环（不依赖 AI 也能跑通）✅

- IndexedDB 持久化的 zustand store（7 个域）
- `HydrationGate` 解决异步 hydration 导致的空状态闪动
- **规则排期算法** `buildSchedule`：deadline 优先、单日上限硬约束、单元优先完整 —— 13 个单测
- 课程创建（手动 + 示例课程）、课程详情、阶段/单元/知识点结构
- 计划生成 → 待办落地（`Todo.planItemId` 是回流的关键）
- 今日待办页：勾选、手动添加、逾期任务、进度
- 提醒调度：`setTimeout` 精确触发 + `visibilitychange` 校准

### P2 · LLM 适配层与对话 ✅

- `lib/llm`：OpenAI 兼容协议实现，含 SSE 流式解析
- 错误翻译层：把 HTTP 状态码与网络异常转成可行动的中文提示（CORS / 鉴权 / 404 / 限流分开处理）
- API 设置页：六家厂商预填、连接测试、密钥本地存储说明
- 对话页：流式输出、停止生成、历史窗口

### P3 · 角色系统 ✅

- 四个内置角色模板（严格督学 / 耐心学长 / 苏格拉底提问者 / 简洁助教）
- 自定义角色：身份、性格、说话风格、教学策略、禁忌
- 内置角色保护：只能「复制后修改」，保证标准参照不被改坏
- 对话中可直接切换角色

### P4 · 记忆系统四层 ✅

- **会话记忆**：历史窗口 + 摘要压缩
- **事实记忆 / 情景记忆 / 掌握状态**：结构化条目
- **写入节流**：每 8 条消息批量抽取 + 手动「记住这个」+ 规则推导（不消耗 LLM）
- **检索注入**：可解释的加权打分（层级权重 × 课程归属 × 关键词重叠 × 新鲜度 × 使用频次）—— 11 个单测
- **掌握状态的诚实边界**：规则只标「学习中」，`已掌握/薄弱` 必须来自 LLM 判断或用户修正 —— 11 个单测
- 记忆面板：可修正、可归档、可删除；知识点掌握热力图

## 已知的未完成项

按重要性排序，如果时间不够会依次放弃：

1. **epub 解析** —— 当前只支持 txt / md
2. **计划自适应** —— 目前完成待办会更新掌握状态，但还不会自动重排后续计划
3. **学习统计** —— 没有学习时长趋势图
4. **对话历史搜索** —— 会话多了之后只能靠标题辨认
