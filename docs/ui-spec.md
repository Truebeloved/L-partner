## 已确认的技术基础（2026-09-25）

- **桌面壳：Electron 44**，安装包用 electron-builder 打 NSIS。
  - 开发：`npm run dev:desktop`（Vite 起服务 → 拉起 Electron 窗口，带 HMR）
  - 打包：`npm run package`（产物在 `release/`，已在 .gitignore 中排除）
  - 只想快速试跑不打包：`npm run package:dir`
- **零返工的部分**：之前为适配静态托管做的两个选择，恰好也是 Electron 从 `file://`
  加载所需要的 —— 相对路径 `base: './'` 与 `HashRouter`。所以现有代码直接就能被桌面壳加载。
- **本机信息读取**：渲染进程在沙箱里，取不到 Node 的 `os` 模块。
  由主进程通过 IPC 提供（`electron/main.cjs` 的 `app:info`），
  预加载脚本只暴露这一个具体能力，不把 `ipcRenderer` 整个交出去。
- **浏览器调试仍然可用**：`npm run dev` 照常能在浏览器里开发调样式（HMR 更快）。
  开屏在这种环境下会回退成「同学」，因为网页拿不到计算机名。
