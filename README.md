# L-partner

> 一个面向学生的**学习辅助工具**：内置互动 AI 答疑，支持课程导入与学习计划生成，配合每日学习待办与学习提醒，把「课程 → 计划 → 执行 → 提醒」串成一条闭环。
>
> 本项目为 OH 社团面试任务作品。

## 项目状态

🚧 **设计讨论阶段（Design phase）** —— 尚未开始编码，正在确定范围与技术方案。

## 规划中的能力

| 模块 | 说明 | 状态 |
| --- | --- | --- |
| 互动 AI | 内置对话式学习助手，答疑、讲解、追问 | 待设计 |
| 课程导入 | 导入课程信息（形式待定：手动 / 文本粘贴 / 课表文件） | 待设计 |
| 课程分析 | 解析课程结构、知识点与考核方式 | 待设计 |
| 学习计划 | 基于课程与可用时间生成可执行的学习计划 | 待设计 |
| 每日待办 | 每日学习任务清单，支持完成状态与进度 | 待设计 |
| 学习提醒 | 到点弹窗 / 系统通知提醒学习 | 待设计 |
